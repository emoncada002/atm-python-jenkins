# ATM Python Jenkins

Proyecto de Integración Continua para la materia de DevOps.

## Tecnologías

- Python
- Git
- GitHub
- Jenkins
- AWS EC2

## Descripción

Aplicación sencilla de cajero automático desarrollada en Python.

El proyecto utiliza Jenkins para automatizar la integración continua,
la instalación de dependencias y la ejecución de pruebas.
